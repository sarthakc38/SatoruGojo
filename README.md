## 🌀 About the Project

A sleek, responsive **tribute website** dedicated to **Satoru Gojo** from *Jujutsu Kaisen (JJK)*. Built with pure **HTML, CSS & JavaScript**, this project brings his character lore to life through stunning visuals and a **Domain Expansion**-inspired UI animation. 🤞✨

> "Throughout Heaven and Earth, I alone am the Honored One." 😎

---

## ✨ Features

- 🔵 **Domain Expansion Animation** — eye-opening & hand-sign frame sequences for that iconic reveal effect
- 🎬 Embedded MP4 clips (`eyes opening.mp4`, `hand-sign.mp4`) for cinematic transitions
- 🖼️ Frame-by-frame image sequences for smooth custom animation (no heavy animation libraries!)
- 📱 Fully responsive layout
- 🎨 Clean, dark, anime-inspired UI

## 🚀 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/sai-vignesh-ops/Gojo_satarou_Animation.git
   ```
2. **Move into the project folder**
   ```bash
   cd Gojo_satarou_Animation
   ```
3. **Open `index.html`** in your browser — that's it, no build step needed! 🎉
   ```bash
   # macOS
   open index.html
   # Windows
   start index.html
   # Linux
   xdg-open index.html
   ```
